# Mars end-to-end scenario

This folder is the short Russian science-fiction run for a Linux GPU machine.

`synopsis.md` is the prompt the pipeline reads. `outline.md` is a hand-written scene list for a person who wants to compare what the model did. The outline is not passed into the model, and `scripts/e2e_mars.sh` does not load it.

The story is fiction. SpaceX may appear as the company. The crew and mission control are invented. Do not add real people as characters.

Run instructions live in `docs/bakeoff.md` under the Mars heading, and in the repository README.
